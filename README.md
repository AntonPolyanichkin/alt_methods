# Construction & Engineering Company Website

A modern, multilingual website for a professional construction and engineering company specializing in **rope access, high-altitude, facade, maintenance, and hard-to-reach works**.

The project is designed to position the company as a **serious European construction and engineering contractor**, rather than an extreme-sports or climbing-gear brand.

## Overview

The website presents a calm, professional and international visual identity focused on:

- Construction and engineering services
- Facade repair and maintenance
- High-altitude and hard-to-reach works
- Rope access technologies
- International projects
- Safety and technical expertise
- Completed projects and company experience

The main concept is to communicate **the result and service the client needs**, while presenting rope access as a professional technical method used to solve difficult access problems.

## Design Concept

The visual direction follows a restrained European B2B / construction aesthetic:

- Minimal and spacious layouts
- Large real-world photography
- Generous whitespace
- Neutral backgrounds
- Dark structural color palette
- Limited safety/construction accent color
- Modern sans-serif typography
- Clear visual hierarchy
- Strong focus on photography and completed projects

The design intentionally avoids:

- Extreme-sports aesthetics
- Excessive safety-orange colors
- Heavy gradients
- Glossy 3D elements
- Generic stock photography
- Cluttered layouts
- Template-like Bootstrap styling
- "Guys on ropes" positioning

The goal is to make the company look like an **established construction and engineering contractor with specialized rope-access capabilities**.

## Main Features

### Services

The website focuses on practical, client-oriented services:

- Facade Repair
- Structure Installation
- Sealing & Waterproofing
- Roof Repair
- Painting
- Construction Works
- Building Maintenance

Rope access is presented as a **technical method** used when scaffolding, cranes or other lifting equipment are impractical or not cost-effective.

The website supports three languages:

The language switcher is available in both the header and footer.

The layouts are designed to accommodate different text lengths between languages.

### Responsive Design

The website is designed for both desktop and mobile devices.

Key responsive considerations include:

- Mobile navigation
- Stacked content sections
- Responsive project galleries
- Mobile-friendly quote forms
- Reduced hero height on smaller screens
- Preserved visual impact of photography

## Positioning

A key UX decision of the project is that **"Industrial Climbing" / "Rope Access" is not used as the primary navigation category**.

Instead, users see services based on their actual needs:

> Facade Repair → Structure Installation → Waterproofing → Roof Repair → Painting → Construction Works → Building Maintenance

Rope access is then introduced within the relevant service pages as the technical solution.

This approach allows the website to communicate:

**"We solve difficult construction and maintenance problems."**

rather than:

**"We are a company that climbs buildings."**

## Visual Direction

The interface is inspired by modern European construction and engineering websites, with an emphasis on:

- Technical professionalism
- Reliability
- Safety
- International experience
- Architectural photography
- Clear information architecture

The design aims to establish trust before the user even reads the technical details.
